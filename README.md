# 🌍 LinguaXplore – Site Web Officiel

Bienvenue sur le **site officiel de LinguaXplore**, l'application immersive qui réinvente l'apprentissage des langues grâce à la **réalité virtuelle (VR)**, la **réalité augmentée (AR)**, l’**IA conversationnelle** et la **gamification**.

---

## 📁 Structure du projet

Voici l’organisation actuelle du code source :

```
linguaxplore-site/
├── assets/                    # Images, icônes, logos
├── pages/                    # Pages secondaires HTML
│   ├── contact.html
│   ├── News.html
│   ├── purchase1.html
│   └── purchase2.html
├── scripts/                  # Scripts JS spécifiques aux pages
│   ├── contact.js
│   ├── News.js
│   └── purchase1.js
├── styles/                   # Fichiers CSS spécifiques aux pages
│   ├── contact.css
│   ├── News.css
│   ├── purchase1.css
│   └── purchase2.css
├── index.html                # Page d'accueil principale
├── script.js                 # Script JS principal
├── style.css                 # Feuille de style globale
└── README.md                 # Documentation du projet
```

---

## 🎯 Objectifs du site

- Présenter le projet LinguaXplore au grand public
- Mettre en avant les fonctionnalités immersives (AR/VR)
- Proposer un point de contact avec l’équipe
- Permettre un accès rapide aux pages d’achat ou de test
- Offrir des mises à jour via la section News

---

## 🧠 Technologies utilisées

- **HTML5** – Structure du contenu
- **CSS3** – Mise en forme et responsive design
- **JavaScript Vanilla** – Interactions et logique de base
- (Prévu) **Firebase / Netlify** – Hébergement et formulaire
- (Facultatif) **Figma** – Maquettes UI

## 🚀 Déploiement

Le projet est prévu pour un hébergement statique (Netlify / Firebase Hosting).

### Exemple Netlify :
1. Connecter le repo GitHub
2. Sélectionner `index.html` comme page de base
3. Déploiement auto à chaque `push`
